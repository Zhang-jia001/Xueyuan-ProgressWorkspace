2必须先处理的口径矛盾（8 项）

以下问题全部来自公开数据的直接比对，不需要等任何内部数据。第 1、2、3 项属对外承诺与实际交付不一致，建议优先修正。
1同名模块跨越两个段位重复出现
模块名「AI 全流程开发实战」在 S3 与 S4 各出现一次：S3 是单体版（5 章 / 25 课时），S4 是微服务版（5 章 / 24 课时）。两者名称完全相同、内容不同。
影响教务与学员都无法从名称区分两个模块；若按模块名做统计或建索引会直接合并成一条，导致课时数虚高、进度计算错位。建议改名为「AI 全流程开发实战（单体）」与「（微服务）」。
2段位数量与宣传口径不符
课程主描述写「青铜到王者五大段位」，但只列了 4 个（青铜 188 / 白银 134 / 黄金 191 / 钻石 222）；系统 learning-paths 实际有 6 个 Level。多出的 S5「黄金进阶」（108 学时）与 S6「Agent 开发工程师」（26 学时）在课程宣传文案里完全没有出现。
影响宣传页与课程页的段位数、名称、学时三处口径不一致，学员按宣传页理解会漏掉 134 学时内容。
3青铜段位学时对不上
宣传口径：青铜 188 学时；系统 learning-paths：S1 estimatedHours = 162。差 26 学时。
影响对外承诺的学习量与实际交付差 14%，属可被追责的口径差。
4白银段位学时字段为空
S2 的 estimatedHours = null。但宣传口径写「白银 134 学时」，且按其 208 课时占 S1 的 253 课时比例推算 ≈ 133 学时，与宣传吻合。
影响判断为字段漏填而非内容缺失。前端若按学时排序/展示会出空值。需补数据，不是补内容。
5S5 段位命名断裂
宣传说「到王者」，但 S5 的系统描述写的是「黄金进阶」——「黄金」段位名被重复使用，王者段位名未落地。
影响段位体系没有闭环，进度激励（青铜→王者）的最后一环缺少明确命名与标识。
6S2 排序字段异常
6 个 Level 的 order 分别是 1 / 0 / 3 / 4 / 5 / 6，只有 S2 是 0。
影响疑似录入错误，可能导致学习路径在页面上排序错乱，S2 掉到最前或最后。
7S6 内容与另一门课重复挂载
S6 的章节 order 从 197 跳到 10003-10038，内容是商城里的独立课程「AI Agent全栈应用」(genai-app-v2)。该课程在商城 status = draft（未上线），但内容已挂在 java-camp 里作为 S6 交付。
影响同一套 112 课时内容在两个课程下各挂一份，且源课程未上线。存在维护双份与权限口径混乱风险。
8S5 / S6 没有实训项目
S1-S4 各有一个实训项目（奶茶物语 42 课时 / 社团报名通 51 / 智学云 103 / 医枢云 63），S5 与 S6 的 0 个。
影响课程承诺「学完即拥有可上线的项目作品集」，但作品集只到 S4 就断了。S5+S6 共 134 学时（16% 的课程量）没有产出物。

5对线下学习服务的结构性判断

可标准化、适合线下面授

  • S1 + S2（22 周 / 296 学时 / 12 模块）：模块边界干净，每个模块 12-73 课时，天然可切成周单元
  • 4 个实训项目是天然的线下交付节点：奶茶物语、社团报名通、智学云(103课时)、医枢云(63课时)
  • 视频占比高（S1 66.8%、S2 76.0%）：适合「线下集中观看 + 现场跟练 + 助教巡场」的服务模式
  • 每段位可独立结业：6 段位清晰分段，支持分阶段交付与分阶段收费

结构性风险，需先补内容再排课

  • S5 内容最碎：108 学时塞了 13 个模块，平均每模块仅 0.6 周（约 4 天），无法直接排成周课，必须重组为专题包
  • S5 + S6 零实训项目：134 学时（16% 课程量）无产出物，「作品集」承诺到 S4 断裂
  • S6 全是图文：112 课时 0 视频，不适合集中面授，只适合「自习 + 线上答疑」
  • S6 是外部课程拼装：order 跳跃至 10003，源课程 genai-app-v2 仍是 draft 状态

6数据说明

已获取：课程元数据、6 个 Level 定义、233 章标题与章序、1357 个课时的标题 / 类型 / 顺序，以及商城全部 5 门课的上下架状态与学员数。这部分无需登录，可直接对接内部系统比对。

未获取：课时正文、视频地址、学习进度 —— 这三类接口实测返回 401 Access token required。视频时长字段（duration）全量缺失（1357 个课时中仅 112 个非零），因此上表所有「学时」均使用平台自行标注的 estimatedHours，未做二次校验。若要核算真实交付时长，需要内部导出课时表。

待确认口径：1 学时 = 45 分钟还是 60 分钟。平台「S1 = 162 学时 = 81 天」的口径是每天 2 学时，但未标注单位。学习计划据此给出两套换算。
