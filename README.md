# 学员学习进度台 · Xueyuan ProgressWorkspace

一个面向**课程交付运营**的单文件学习进度看板：把「进度百分比」还原成**当前在哪一章、这周该学什么、什么时候能学完、谁需要立刻打电话**。

零依赖，双击 HTML 即可打开，无需安装任何环境，可离线使用、可直接打印。

> ⚠️ **本仓库为脱敏版本**：学员姓名统一编号为「学员01–学员35」，手机号已全部移除，团队名抽象为「团队A / 团队B」。原始回访数据与含真实信息的看板**不在本仓库内**。

---

## 它解决什么问题

课程运营通常只能看到平台后台的一个「完成度 X%」。这个数字无法直接支撑任何行动——你既不知道他卡在哪一章，也不知道按现在的速度何时能学完，更看不出「学得慢」到底是**没来**还是**学不会**。

本项目把单一进度数字拆成四条可执行链路：

| 链路 | 输入 | 输出 |
|---|---|---|
| 进度 → 章节 | 完成度 %、最后提交的作业 | 精确定位到 233 章中的哪一章 |
| 投入 → 毕业周期 | 累计时长、开通天数、每周实际投入 | 学完需要几周、哪个情景能压进一年 |
| 行为 → 干预优先级 | 静默天数、窗口占用、每课时耗时 | P0–P3 分级 + 可直接照做的动作 |
| 情景 → 曲线 | 投入强度、习惯爬坡、疲劳衰减 | 三档情景下 52 周进度曲线 |

## 核心算法

### 1. 进度百分比 → 精确章节

```
已学课时 = 完成度% × 1357（课程总课时）
```

将已学课时落入按顺序累加的章节课时区间，得到「推算章节」；再用「最后一次提交的作业」做锚点交叉校验，两者相差超过 2 章时标记为不同步（可人工指定章号覆盖）。

实测 35 人中 12 人精确对齐，其余偏差 ≤2 章（进度为整数百分比，1% ≈ 13.6 课时，存在量化误差）。

### 2. 学习曲线推演（预测层）

每周推进量为三个因子的乘积：

```
每周推进课时 = 投入强度 × 习惯爬坡(w) × 疲劳衰减(P)

习惯爬坡  habit(w)   = 1 - exp(-(w+1) / 2.5)          # 前 2–3 周进入状态慢
疲劳衰减  fatigue(P) = 1 - 0.45 × (P/100)^1.5         # 进度越靠后越慢
投入强度  wk         = 每周实际投入小时 × 学习效率（课时/小时，钳制 1.0–2.6）
```

三档情景：

| 情景 | 投入假设 |
|---|---|
| 坐满窗口 | 每周至少 12 小时（院校晚自习 19:00–21:00 × 6 天） |
| 维持现状 | 按当前实际每周投入 |
| 投入回落三成 | 当前投入 × 0.7 |

内部推演 156 周（3 年），图表只采样前 52 周（每 4 周一个点）。这样「一年内学不完」的学员也能给出真实年限，而不是空值。

### 3. 断学风险 → 撑到毕业的概率

```
周中断率 h = 0.5% + 2.5% × (静默天数 - 1) + 1.5% × (75 - 窗口占用%) / 75
          （上限 35%）

撑到毕业概率 = (1 - h) ^ 需学完的周数
```

基础值 0.5% 来自实际数据校准（35 人中仅 1 人真正断学）。静默越久、晚自习越空，中断风险越高，断学 8 天以上基本归零。

### 4. 干预优先级与动作分流

优先级只回答一个问题：**要不要打电话**。

| 级别 | 判据 |
|---|---|
| P0 | 断学 ≥ 7 天 |
| P1 | 每周投入不足窗口一半 / 每课时耗时达标准 1.5 倍 / 断学 4 天 |
| P2 | 出勤未满 75% / 超出一年线 / 节奏落后 |
| P3 | 正常 |

动作按**问题类型**分流，因为「没来」和「学不会」的解法完全相反：

| 类型 | 判据 | 动作 |
|---|---|---|
| 出勤不足 | 窗口占用 < 60%，每课时耗时正常 | 先不谈学什么，要求每晚坐满 2 小时 × 5 天 |
| 效率卡点 | 每课时耗时 ≥ 0.72h（标准 0.48h 的 1.5 倍） | 不再加时间，共享屏幕陪跑一章查卡点 |
| 问题叠加 | 两者同时成立 | 一次只解决一个，先出勤、后效率 |
| 刷课信号 | 每课时 < 0.25h | 抽查最近 3 章作业，讲不出代码就作废进度重学 |

## 使用方式

```bash
# 直接查看
open 学员学习进度台-demo.html

# 重建（需自备回访数据 xlsx）
python3 build.py
```

`build.py` 默认读取项目根目录下的回访表（`*学员回访_*.xlsx`）与课程结构 CSV，输出单文件 HTML。原始数据格式：

| 字段 | 说明 |
|---|---|
| 姓名 / 手机号 / 学校 / 班级 / 班主任 | 学员基础信息 |
| 进度(%) | 平台统计的课程完成度 |
| 学习时长(分钟) | 累计学习分钟数 |
| 最后学习时间 / 开通时间 | 用于计算静默天数与开通天数 |
| 最后一次提交的作业 | 用于章节锚点校验 |

## 页面功能

- **进度总览**：35 人 KPI、段位分布、卡点模块聚集、班级进度排名
- **12 个月预测带**：三档情景下各有多少人能在一年内学完
- **学员明细表**：可排序筛选（团队/班主任/学校/段位/优先级/搜索），点击行看详情
- **学员详情抽屉**：段位路径、投入指标、节奏对比、52 周学习曲线（SVG）、个性化学习计划
- **干预清单**：按优先级排序，每人配一条具体动作
- **个人学习计划书**：可打印 / 存 PDF 的完整计划（含四周边界任务、段位里程碑）
- **学员录入**：13 字段表单，实时预览会定位到哪一章、哪天学完，支持编辑与导出 CSV

## 技术说明

- **单文件交付**：所有数据、样式、脚本内联，无外部依赖、无网络请求
- **图表手绘**：预测曲线用原生 SVG 绘制，未引入图表库
- **前后端同构**：`build.py`（Python）与页面内 `compute()`（JS）实现同一套算法，两侧结果逐字段一致，由 21 项一致性测试守护
- **舍入口径**：统一 half-up（`floor(x*n+0.5)/n`），避免 Python 银行家舍入与 JS `Math.round` 在 `.5` 边界相差 0.1
- **本地优先**：录入数据存 `localStorage`，可导出 CSV 回灌构建流程，不依赖任何后端
